## Границы проверки

PGlite выполняет SQL в PostgreSQL, но не запускает инфраструктуру Supabase Auth/PostgREST. Роли и `auth.uid()` воспроизводятся в тесте, неиспользуемый в запросах pgcrypto пропущен; UUID генерирует встроенная функция PostgreSQL.

HTTP-тесты и production-тесты браузера используют подмену сетевого API; они не подтверждают запись в облачный Supabase. Облачный проект, ключи frontend, аккаунт организатора и GitHub Pages ещё должен настроить владелец по DEPLOYMENT.md. Секреты в исходники не добавлялись.

При подготовке 15 октября создание удалённой ветки через подключённый GitHub было отклонено с 403; были подготовлены Git bundle и архив исходников.
