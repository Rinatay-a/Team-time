## Найденное критичное исправление

Исходные миграции 001+002 воспроизвели ошибку PostgreSQL `column reference "participant_id" is ambiguous` при реальном сохранении. Миграция 003 исправляет её без изменения исходных миграций и без удаления ответов. Проверка после 003 выполняет успешные сохранение и редактирование.

## Границы проверки

PGlite выполняет SQL в PostgreSQL, но не запускает инфраструктуру Supabase Auth/PostgREST. Роли и `auth.uid()` воспроизводятся в тесте, неиспользуемый в запросах pgcrypto пропущен; UUID генерирует встроенная функция PostgreSQL.

HTTP-тесты и production-тесты браузера используют подмену сетевого API; они не подтверждают запись в облачный Supabase. Облачный проект, ключи frontend, аккаунт организатора и GitHub Pages ещё должен настроить владелец по DEPLOYMENT.md. Секреты в исходники не добавлялись.

Создание удалённой ветки через подключённый GitHub отклонено с 403. PR и облачная публикация не выполнялись. Подготовлены локальная ветка, Git bundle и архив исходников; порядок загрузки описан в START_HERE.md.
