## Типографика и объём

Montserrat — интерфейс, формы, календари, рабочие заголовки 400/500/600/700. Unbounded 500 — только название сервиса на главной. Три оригинальных WOFF2-подмножества занимают 93 208 байт, лицензии SIL OFL приложены в `public/fonts`. На рабочих страницах загружаются только два подмножества Montserrat. Дополнительных npm-зависимостей нет.

Обе UI-гарнитуры поддерживают русскую кириллицу, включая Ё/ё; в Latin-подмножестве есть цифры и типографская пунктуация. Chromium подтвердил отрисовку русского названия локальным Unbounded и описания — локальным Montserrat, не системным fallback. Все три файла в production доступны с HTTP 200 по `/Team-time/fonts/…`.

UI-шрифты предзагружаются, используются `font-display: swap`, явные межстрочные интервалы и fallback с согласованными метриками. При искусственной задержке шрифтов на 1000 мс измеренный CLS: 0,00005 на 390 px и 0,00002 на 1440 px.

## Проверки

- `npm run lint` — без замечаний.
- `npm test` — 61 тест прошёл.
- `npm run test:e2e` — 3 сценария выделения мышью/пальцем и смены недели прошли.
- `npm run test:pages` — production-сборка и 2 браузерных сценария прошли: прямые ссылки, локальные шрифты, сохранение/редактирование, два устройства, вход организатора, создание обоих типов опроса и мобильные результаты.
- Главная, вход, панель организатора, создание опроса, календарь участника и результаты проверены при ширинах 320/360/390/768/1024/1440 px. Горизонтальной прокрутки страницы нет; широкая рабочая сетка сохраняет собственную внутреннюю прокрутку и размеры ячеек.
- На странице результатов добавлен только `grid-cols-1`, чтобы на узком экране содержимое не расширяло внешнюю grid-колонку. Остальные рабочие страницы сохраняют свои макеты.

Авторизация проверяется существующим production E2E с подменой HTTP API. Адаптивность рабочих страниц проверена на локальных демоданных. Эти проверки не создают записи в настоящем Supabase.

Backend, миграции, Edge Function, сервис API, алгоритмы времени, маршруты, зависимости, workflows и переменные окружения не изменены. Обработчики сессии в Layout сохранены; изменена только оболочка. Ветка предназначена для визуального согласования через PR; публикации в main нет.
