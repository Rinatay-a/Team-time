- Восстановлен workflow проверок и GitHub Pages; корректный путь `/Team-time/`, публикация только из `main` после тестов.
- Добавлен ручной workflow развёртывания Supabase; настройки функции перенесены в `supabase/config.toml`.
- Production-сборка запрещает демо, отсутствующую конфигурацию и секретные ключи.

- Клиент сохраняет код конфликта из HTTP 409. Сервер проверяет ошибки административных изменений и полную принадлежность слотов сетке.
- Добавлены проверки PostgreSQL/RLS, HTTP-обработчика функции и production-сборки на двух браузерах.
- Добавлены `npm run check:backend` и подробная инструкция запуска без передачи секретов в чат.

## 2.0.0 — 14 октября 2026

### Новое
- Два типа опросов: **сбор свободного времени** и **планирование встречи**.
- Периоды до 56 выбранных дней, быстрые диапазоны 7/14/21/28/42 дня и фильтр дней недели.
- Недельный календарь на компьютере и дневной календарь на телефоне.
- Онбординг участника: имя → краткая инструкция → календарь → подтверждение записи.
- Настоящее pointer-выделение мышью и пальцем с добавлением/удалением диапазона.
- Локальный черновик на семь дней, предупреждение о несохранённых изменениях и защита черновика от polling.
- Анализ свободного опроса блоками 30/60/90/120/180 минут без обязательной финализации.
- Детали слота для организатора и недельная тепловая карта.
- Playwright-тесты мыши, touch, отмены жеста и сохранения выбора между неделями.

### База и API
- Миграция `002_poll_types_and_atomic_availability.sql`; `001_initial.sql` не менялась.
- Существующие записи автоматически получают `poll_type='meeting'`.
- `meeting_duration` разрешён как `NULL` только для `availability`.
- Атомарное сохранение участника и слотов через транзакционную PostgreSQL-функцию.
- Оптимизированные JSON-снимки не обрезают ответы длиннее стандартного лимита PostgREST в 1000 строк.
- Оптимистическая блокировка по `updated_at` для конфликта двух вкладок.
- Серверная проверка существования даты, формата времени, шага, границ, статуса и типа опроса.
- Финализация запрещена для опросов свободного времени и проверяется по датам/сетке/длительности.

### Исправлено
- Pointer capture больше не назначается отдельной ячейке; соседние ячейки определяются централизованно через координаты.
- Фоновое обновление больше не уничтожает несохранённый выбор.
- Удаление старых слотов и вставка новых больше не являются двумя неатомарными запросами.
- Московская дата формы не вычисляется через UTC `toISOString()`.
- Демо не включается молча при отсутствии переменных production.
- Исправлен CSV: единый упорядоченный набор колонок.
- Добавлено корректное экранирование ICS.
- Ошибки clipboard, закрытия опроса и финализации отображаются пользователю.

### Зависимости
- Vite 7, Vitest 4, ESLint 10 и Tailwind CSS 4.
- Удалены устаревшие цепочки старых Vitest/jsdom/Tailwind.
- После обновления `npm audit` и `npm audit --omit=dev` показывают 0 известных уязвимостей в проверенном окружении.
