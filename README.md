# Время команды 2.0

Русскоязычный сервис для Молодёжной палаты Чертанова Центрального. Участники без регистрации отмечают доступность, организатор видит недельную тепловую карту.

## Два режима

1. **Сбор свободного времени** — период до 56 выбранных дней, длительность встречи не задаётся и итоговое время не навязывается. При необходимости организатор анализирует блоки выбранной длительности.
2. **Планирование встречи** — прежний сценарий одной встречи: длительность, топ непрерывных интервалов, финализация и `.ics`.

Старые UUID, `/#/meet/:id`, участники и токены остаются совместимыми: миграция присваивает существующим опросам тип `meeting`.

## Возможности

- диапазоны 7/14/21/28/42 дня, выбор дней недели;
- недельный desktop-календарь и дневной mobile-календарь;
- drag мышью и touch: жест по пустой клетке добавляет, по выбранной удаляет;
- локальный черновик на семь дней, защита от потери при polling и сетевой ошибке;
- атомарное серверное сохранение 2352 и более допустимых слотов;
- оптимистическая блокировка конфликтов двух вкладок;
- тепловая карта, состав свободных/несвободных, CSV;
- Supabase Auth, Edge Function, RLS и запрет прямого anon-доступа;
- явный демо-режим, HashRouter и GitHub Pages.

## Быстрый запуск

Требуется Node.js 20.19+.

```powershell
npm ci
Copy-Item .env.example .env.local
# заполните .env.local
npm run dev
```

Без Supabase приложение **не** включает демо автоматически. Для явного локального демо:

```powershell
$env:VITE_DEMO_MODE="true"
npm run dev
```

## Безопасность и персональные данные

Frontend содержит только publishable/anon key. `service_role` существует исключительно в окружении Supabase Edge Function. Admin-операции проверяют JWT через `auth.getUser()` и `organizer_id`; `--no-verify-jwt` нужен для публичного входа участников и не отменяет серверную проверку админских методов.

Токен редактирования — случайные 256 бит; в БД хранится SHA-256. Совпадение имени не даёт доступ к чужому ответу. При видимости «только организатор» публичный API не возвращает чужие ФИО и расписания.

ФИО и доступность являются персональными данными. Владелец должен определить срок хранения, порядок удаления и правовое основание. Размещение на иностранной инфраструктуре Supabase может требовать отдельной юридической проверки; проект не заявляет автоматического соответствия законодательству.
